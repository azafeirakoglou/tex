# Οδηγός συγγραφής — σταθερή διεπαφή v1.0

Το καθαρό σημείο εκκίνησης είναι τα `starter.tex` / `starter-print2.tex`.
Μοιράζονται το `starter-content.tex`, επομένως το κείμενο γράφεται μία φορά.
Τα `main.tex` / `main-print2.tex` διατηρούνται ως κατάλογος παραδειγμάτων.
Το μικρό περιεχόμενο του starter είναι υπόδειγμα σύνταξης και αντικαθίσταται
με τη δική σου ύλη πριν τη δημοσίευση.

## Πρώτη παραγωγή

Ακολούθησε το [SETUP.md](../SETUP.md) για τα εργαλεία. Από τη ρίζα του έργου:

```sh
make setup
make -j2 starter-screen starter-print2
```

Παράγονται τα `build/starter-screen/Starter_Screen.pdf` και
`build/starter-print2/Starter_Print.pdf`. Χρησιμοποιούμε XeLaTeX μέσω των
εντολών `make`, ώστε να φορτώνονται οι σωστές γραμματοσειρές και να
ενημερώνονται αυτόματα τα περιεχόμενα και οι παραπομπές.

Για νέο βιβλίο:

1. Αλλάζουμε τίτλο, συγγραφέα και λοιπά στοιχεία στο `config/book-config.tex`.
2. Αντικαθιστούμε το `chapters/starter-chapter.tex` ή γράφουμε νέο αρχείο.
3. Προσθέτουμε τη σειρά κεφαλαίων στο `starter-content.tex`, π.χ.
   `\include{chapters/chapter-02}` χωρίς επέκταση `.tex`.
4. Παράγουμε και ελέγχουμε και τις δύο εκδόσεις.

## Κεφάλαια, τίτλοι και κεφαλίδες

Άνοιγμα χωρίς φωτογραφία, με τέσσερις έως έξι σύντομους στόχους:

```tex
\BookChapter{Τίτλος κεφαλαίου}{Σύντομος υπότιτλος}{%
  \item Πρώτος μαθησιακός στόχος.
  \item Δεύτερος μαθησιακός στόχος.
  \item Τρίτος μαθησιακός στόχος.
  \item Τέταρτος μαθησιακός στόχος.
}
\section{Τίτλος ενότητας}
```

Τα custom ανοίγματα υποστηρίζουν προαιρετικό σύντομο τίτλο:
`\BookChapter[Σύντομος]{Πλήρης τίτλος}{υπότιτλος}{στόχοι}`. Ο πλήρης τίτλος
παραμένει στη σελίδα ανοίγματος και στα περιεχόμενα· ο σύντομος χρησιμοποιείται
μόνο στην κεφαλίδα. Το ίδιο ισχύει για τη `\BookChapterPhoto[Σύντομος]{...}`.

Τα ανοίγματα προσαρμόζουν το χρωματιστό ύψος σε μεγάλους τίτλους. Στη
φωτογραφική διαδρομή το εικαστικό περιορίζεται στον διαθέσιμο χώρο, ώστε
οι στόχοι να μένουν στην ίδια σελίδα. Εξαιρετικά μεγάλοι τίτλοι/στόχοι που
δεν χωρούν δίνουν σαφές σφάλμα αντί να κρύβουν κείμενο.

Η κανονική `\chapter[Σύντομος τίτλος]{Πλήρης τίτλος}` και η
`\section[Σύντομος τίτλος]{Πλήρης τίτλος}` ακολουθούν τη συνηθισμένη LaTeX:
η σύντομη ονομασία χρησιμοποιείται σε κεφαλίδα και περιεχόμενα. Για μεγάλους
τίτλους δίνουμε σύντομη μορφή, χωρίς να μικραίνουμε τη γραμματοσειρά κεφαλίδας.

Οι τίτλοι κεφαλαίου και ενότητας εμφανίζονται χωρίς αριθμούς στην κεφαλίδα,
με Inter Regular 8 pt. Η `\BookSection{Θεωρία}` είναι οπτική θεματική λωρίδα:
δεν δημιουργεί αριθμημένη ενότητα ούτε αλλάζει μόνη της την κεφαλίδα.
Τα φύλλα εργασίας και τα κριτήρια παραμένουν στο κεφάλαιο που τα περιέχει.

Η `\BookChapterPhoto{τίτλος}{υπότιτλος}{asset}{πηγή}{στόχοι}` χρησιμοποιεί
δηλωμένο εικαστικό. Δεν απαιτείται φωτογραφία για να αρχίσει νέο βιβλίο.

## Σταθερές παράμετροι μακέτας

Στο `config/book-config.tex` ρυθμίζονται κοινά μεγέθη και εμφάνιση. Η έκδοση
v1.0 έχει σελίδα 170 × 240 mm, εσωτερικό περιθώριο 20 mm και εξωτερικό 17 mm.
Οι αντικριστές σελίδες αντιστρέφουν τις πλευρές αυτόματα.

Οι `BookFooterMode` (`number` / `full`) και `BookFooterPosition`
(`outer` / `center`) αλλάζουν όλα τα κανονικά υποσέλιδα. Τα ανοίγματα κεφαλαίων,
τα εξώφυλλα και οι σκόπιμα κενές σελίδες έχουν τις τεκμηριωμένες εξαιρέσεις.
Για λεπτομέρειες βλ. [HEADERS.md](HEADERS.md).

## Διδακτικά κουτιά και μαθηματικά

```tex
\begin{ThinkBox}
Σύντομη στρατηγική σκέψης.
\end{ThinkBox}

\begin{AttentionBox}
Η παρατήρηση που χρειάζεται προσοχή.
\end{AttentionBox}

\begin{HistoryBox}[Προαιρετικό ιστορικό θέμα]
Το ιστορικό κείμενο με τεκμηριωμένη πηγή.
\end{HistoryBox}
```

Τα τρία περιβάλλοντα μοιράζονται την ίδια κατασκευή και μπορούν να αλλάξουν
σελίδα. Το εικονίδιο εμφανίζεται στο πρώτο τμήμα. Δεν προσθέτουμε χειροκίνητα
εικονίδια, χρώματα ή `\vspace` για να τα ευθυγραμμίσουμε.

Για εξισώσεις χρησιμοποιούμε την κανονική σύνταξη LaTeX (`equation`, `align`,
`\[...\]`) και `\label` / `\eqref`. Υπάρχουν επίσης `KeyFormula`, `MethodBox`,
`definitionbox` και `theorembox`. Το αρχείο `history-statements-content.tex`
δείχνει αριθμημένους ορισμούς και θεωρήματα. Οι μονάδες SI γράφονται όρθιες,
π.χ. `$\Delta x=4\,\mathrm{m}$`.

## Ερωτήσεις, φύλλα και κριτήρια

```tex
\begin{exercise}[PHY-001]{Σωστό ή λάθος;}
Η πρόταση που θα αξιολογηθεί. \TrueFalseChoices
\end{exercise}
\Answer{Η σύντομη απάντηση.}
```

Για ερώτηση χωρίς τίτλο δίνουμε κενό δεύτερο όρισμα:
`\begin{exercise}[PHY-002]{} ... \end{exercise}`. Ο εσωτερικός κωδικός είναι
μοναδικός και επιτρέπει μεταγενέστερη `\ref{ex:PHY-002}` ή
`\begin{booksolution}{PHY-002} ... \end{booksolution}`.

Σε λίστα σωστό/λάθος χρησιμοποιούμε `\TrueFalseItem{πρόταση}` μέσα σε
`enumerate`. Στην πολλαπλή επιλογή χρησιμοποιούμε το ίδιο `\CheckSquare`:

```tex
\begin{enumerate}[label=\BookGreek*)]
  \item \CheckSquare\; $\mathrm{m}$
  \item \CheckSquare\; $\mathrm{m/s}$
\end{enumerate}
```

Η `\ShowAnswerstrue` / `\ShowAnswersfalse` στον config εμφανίζει ή κρύβει
τις σύντομες `\Answer{...}`. Δεν αφαιρεί χωριστά αρχεία λύσεων· αυτά
προστίθενται ή παραλείπονται από τη σειρά περιεχομένων.

Φύλλο εργασίας:

```tex
\WorksheetOpening{ΚΙΝΗΜΑΤΙΚΗ}{Τίτλος φύλλου}
\WorksheetSection{Α. Παρατηρώ}
Κείμενο δραστηριότητας.
\AnswerLine
```

Κριτήριο αξιολόγησης:

```tex
\begin{Assessment}[student=true,date=true,duration={45 λεπτά}]{Τίτλος}
  \AssessmentTopic{Α}
  \begin{AssessmentQuestion}[5]\label{asq:my-A1}
    Η εκφώνηση.
  \end{AssessmentQuestion}
  \AssessmentPointsCheck[5]
\end{Assessment}
```

Οι προαιρετικές μονάδες είναι ακέραιοι αριθμοί. Η
`\begin{AssessmentSolution}{asq:my-A1} ... \end{AssessmentSolution}`
αναφέρεται αυτόματα στο αντίστοιχο ερώτημα. Για περισσότερη σύνταξη βλ.
`chapters/demo-assessment.tex` και `solutions/demo-assessment-solutions.tex`.

## Πίνακες

Οι σύντομοι πίνακες χρησιμοποιούν `BookStripedTable` ή `BookPlainTable` γύρω
από `tabularx`. Η πρώτη γραμμή αρχίζει με `\BookTableHeaderRow` και κάθε κελί
κεφαλίδας χρησιμοποιεί `\BookTableHead{...}`, όπως στο starter.

Για πολυσέλιδο πίνακα χρησιμοποιούμε `BookLongTable` (ρίγες) ή
`BookLongPlainTable` (λευκές γραμμές), χωρίς εξωτερικό `table`:

```tex
\begin{BookLongTable}[Μετρήσεις\label{tab:measurements}]
  {@{}p{80mm}p{35mm}@{}}
  {\BookTableHead{Μέγεθος} & \BookTableHead{Τιμή}}
  Μήκος & $4\,\mathrm{m}$\\
  Χρόνος & $2\,\mathrm{s}$\\
\end{BookLongTable}
```

Η κεφαλίδα επαναλαμβάνεται στις επόμενες σελίδες. Οι στήλες ορίζονται με
`l`/`c`/`r` ή `p{...}`· το `X` ανήκει στο `tabularx` των σύντομων πινάκων.
Τα πλάτη στηλών πρέπει να
χωρούν στο διαθέσιμο πλάτος, μαζί με τα διάκενα. Οι πολυσέλιδοι πίνακες
χρησιμοποιούνται σε πλήρες πλάτος σελίδας, έξω από `multicols`, `minipage`,
float ή άλλο κουτί που δεν επιτρέπει αλλαγή σελίδας.

## Σχήματα και εικόνες

Το μαύρο χρησιμοποιείται για άξονες, αντικείμενα και γράμματα. Το δεύτερο
μελάνι τονίζει το κύριο στοιχείο του συγκεκριμένου σχήματος· δεν δηλώνει
σταθερά ένα φυσικό μέγεθος. Οι πρόσθετες σειρές διακρίνονται και με μοτίβο.

| Χρήση | Κοινό style |
|---|---|
| Άξονες / διαβαθμίσεις | `book/axis`, `book/tick` |
| Αντικείμενα / σημεία | `book/body`, `book/endpoint` |
| Κύριο / δεύτερο διάνυσμα | `book/mainvector`, `book/secondaryvector` |
| Διάνυσμα αναφοράς | `book/referencevector` |
| Κύρια / δεύτερη καμπύλη | `book/maincurve`, `book/secondarycurve` |
| Βοηθητική γραμμή | `book/guide` |
| Ετικέτα / αριθμός διαβάθμισης | `book/physlabel`, `book/ticklabel` |
| Γράφημα πλήρους πλάτους / στήλης | PGFPlots `book/plot`, `book/plot-column` |
| Σειρές γραφήματος | PGFPlots `book/seriesA`, `book/seriesB` |

Οι ετικέτες είναι 9 pt και οι διαβαθμίσεις 8 pt. Σχεδιάζουμε στο τελικό
μέγεθος: έως 133 mm συνολικό πλάτος σελίδας ή 63,5 mm σε στήλη, μαζί με
άξονες, μονάδες και γράμματα. Αποφεύγουμε `\resizebox` που μικραίνει και τα
γράμματα. Κάθε σχήμα έχει `\caption` και `\label`, ώστε να αναφέρεται με
`Σχήμα~\ref{fig:...}`. Ο οδηγός `figures-guide-content.tex` δίνει πλήρη δείγματα.

Οι εξωτερικές εικόνες δηλώνονται στο `assets` του `config/color-map.json`,
με μοναδικό λατινικό αναγνωριστικό, διαδρομή και `kind` (`raster` ή `tex`).
Μετά εκτελούμε `make colors-regenerate` και χρησιμοποιούμε, για παράδειγμα,
`\BookUseAsset[width=60mm]{experiment_photo}` για το δηλωμένο αναγνωριστικό
`experiment_photo`.
Οι επιλογές `width`/`height` αφορούν raster εικόνες· τα εικαστικά TikZ
ακολουθούν τις δικές τους διαστάσεις. Η PRINT απαιτεί ελεγχόμενα μελάνια και
τόνους· μια αυθαίρετη RGB φωτογραφία δεν γίνεται δίχρωμη με την εισαγωγή της.

## Υποστηριζόμενη χρήση και συμβατότητα

| Σταθερή δημόσια χρήση | Παλιά μορφή που διατηρείται για συμβατότητα |
|---|---|
| `BookStripedTable` / `BookPlainTable` | `BookColorTable` |
| `BookSection` | `BookTheorySection` |
| Γενικά styles έμφασης ανά σχήμα | `book/velocity`, `book/accel`, `book/weight` κ.ά. |
| Παράμετροι `BookHeaderTitleFont` / `BookHeaderTitleColor` | Παλιές `BookHeaderLabel...` |

Για νέο κείμενο χρησιμοποιούμε τη σταθερή δημόσια χρήση. Οι βοηθητικές
εντολές `BookRemember...`, οι εσωτερικοί μετρητές, τα page marks και οι
παραγόμενες παλέτες αποτελούν εσωτερική υλοποίηση. Οι διορθώσεις τους δεν
απαιτούν αλλαγές στα κεφάλαια που ακολουθούν τον παραπάνω κατάλογο.

Η δοκιμασμένη πλατφόρμα εγκατάστασης καταγράφεται στο `SETUP.md`. Δεν έχουν
ελεγχθεί άλλοι μηχανισμοί όπως pdfLaTeX, ούτε αλλαγή της γεωμετρίας σε άλλη
διάσταση βιβλίου χωρίς νέο έλεγχο. Πριν τη διανομή χρησιμοποιούμε την ενιαία
διαδικασία έκδοσης του έργου, η οποία ελέγχει και τα δύο PDF και τα δείγματα.
Οι εκκρεμείς προδιαγραφές του τυπογραφείου παραμένουν στο
[PRESS_PENDING.md](PRESS_PENDING.md).

Τα παλαιότερα README με αριθμό έκδοσης και το `archive/` αποτελούν ιστορικό
υλικό. Για την τρέχουσα χρήση ακολουθούμε τα `README.md`, `SETUP.md` και αυτόν
τον οδηγό.
