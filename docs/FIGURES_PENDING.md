# Κατάσταση διαγραμμάτων και σχημάτων

Οι εργασίες που είχαν καταγραφεί στη v0.46 ολοκληρώθηκαν για τη v1.0.0:
γενικοί χρωματικοί ρόλοι, κοινή τυπογραφία 9/8 pt, πάχη/αιχμές TikZ και
PGFPlots, όρθιες μονάδες SI, μεταφορά των παραδειγμάτων και δείγμα στήλης.

Ο οριστικός οδηγός είναι το [FIGURES.md](FIGURES.md). Η συγγραφική σύνταξη
τεκμηριώνεται στο [AUTHORING.md](AUTHORING.md). Οι εκκρεμείς τιμές του
τυπογραφείου παραμένουν στο [PRESS_PENDING.md](PRESS_PENDING.md).
