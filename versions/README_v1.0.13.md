## Έλεγχοι και έκδοση

Πέρασαν 66 δοκιμές, 40 πρόσθετες μεταγλωττίσεις, 30 έλεγχοι ζευγών PDF,
οι ειδικές μετρήσεις των νέων στοιχείων και πραγματική οπτική θέαση 76 σελίδων.
Η καθαρή offline εγκατάσταση αναπαρήγαγε και τα δύο κύρια PDF.

Η κεφαλίδα λυμένων παραδειγμάτων Α παραμένει προεπιλογή. Η Β είναι προαιρετική.
Δεν άλλαξε επιστημονικό περιεχόμενο και καμία προηγούμενη stable δεν αντικαταστάθηκε.

Το commit/push εξουσιοδοτήθηκε ρητά στο brief της v1.0.13. Διατηρείται ο υπάρχων
ανεξάρτητος κλάδος `stable-v1.0.12`, χωρίς force push ή merge στο main.
Δεν δημιουργείται ξεχωριστό GitHub Release ή tag με αυτή την ανάρτηση.

Οι τελικές προδιαγραφές του τυπογραφείου για συγκεκριμένο κόκκινο spot,
τονικότητες και ξάκρισμα παραμένουν εκκρεμείς. Δεν δηλώνεται πιστοποίηση PDF/X.
