# Universal Book Template v1.0.12 STABLE — λήψεις

Η v1.0.12 βασίζεται αποκλειστικά στη v1.0.11 MINIMAL. Προεπιλογή κεφαλίδας
λυμένου παραδείγματος: A. Η B διατηρείται ως προαιρετική εναλλακτική.

Η ανάρτηση έγινε σε χωριστό κλάδο με ρητή έγκριση του χρήστη στις
6 Νοεμβρίου 2026. Το main και οι παλαιότερες εκδόσεις παραμένουν ανέπαφα.
Δεν έγινε merge, δημιουργία tag ή GitHub release.

## Πηγές και έλεγχοι

Ο πλήρης φάκελος [Universal_Book_Template_v1.0.12_STABLE](Universal_Book_Template_v1.0.12_STABLE/)
περιέχει τον πηγαίο κώδικα, τις γραμματοσειρές και άδειες, τα PDF, οδηγίες
αναπαραγωγής, QA report και CHANGELOG. Τα προσωρινά builds/caches και οι
παλιές διαγνωστικές δοκιμές δεν περιλαμβάνονται στο πακέτο.

Πέρασαν 66 δοκιμές, 40 πρόσθετες μεταγλωττίσεις και 29 έλεγχοι ζευγών PDF.
Η διόρθωση των πολυσέλιδων πινάκων επαληθεύτηκε σε δέκα οριακές περιπτώσεις.
Έγινε πραγματική οπτική εξέταση των PDF και καθαρή offline επανεγκατάσταση.

Οι φάκελος και ZIP αναρτήθηκαν ακριβώς όπως ελέγχθηκαν. Οι αναφορές τους
περιγράφουν την τοπική παραγωγή πριν από τη χωριστή άδεια ανάρτησης.
Η παρούσα δημοσίευση δεν υποκαθιστά τις εκκρεμείς προδιαγραφές τυπογραφείου
και δεν αποτελεί πιστοποίηση PDF/X.
