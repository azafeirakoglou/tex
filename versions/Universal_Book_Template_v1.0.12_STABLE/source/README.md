# Universal Book Template v1.0.12 — πηγαίος κώδικας

Η μακέτα προέρχεται αποκλειστικά από την **B — MINIMAL της v1.0.11**.
Υπάρχει μία εκδοτική ταυτότητα. Οι A/B της v1.0.12 αφορούν μόνο την
κεφαλίδα λυμένων παραδειγμάτων, όχι διαφορετικά σχέδια ολόκληρου βιβλίου.
Η τελική κατάσταση stable και οι έλεγχοι καταγράφονται στη ρίζα του πακέτου.

Ελληνική μακέτα XeLaTeX για Φυσική, Χημεία και Μαθηματικά, 170 × 240 mm.
Το PRINT κρατά μαύρο και το υπάρχον κόκκινο spot. Το SCREEN κρατά μαύρο
και μπλε `#203B63`. Τονικότητες: 100%, 55%, 10%. Δεν αλλάζουν η παλέτα,
οι υπάρχοντες χρωματικοί ρόλοι ή η γεωμετρία μεταξύ PRINT/SCREEN.

## Πρώτη χρήση

Αντιγράφουμε όλο το πακέτο v1.0.12 σε νέο φάκελο και ακολουθούμε
[SETUP.md](SETUP.md) και [../REPRODUCTION.md](../REPRODUCTION.md).
Δεν αντικαθιστούμε αρχεία προηγούμενης stable.

Το `starter.tex` / `starter-print2.tex` είναι καθαρό σημείο εκκίνησης.
Μοιράζονται `starter-content.tex` και `chapters/starter-chapter.tex`.
Αλλάζουμε στοιχεία στο `config/book-config.tex`, γράφουμε τα δικά μας
κεφάλαια και ορίζουμε τη σειρά τους στο `starter-content.tex`.
Τα `main.tex` / `main-print2.tex` διατηρούν το πραγματικό δείγμα βιβλίου.

## Κοινές ρυθμίσεις

| Αρχείο | Περιεχόμενο |
|---|---|
| `config/book-config.tex` | Βασικές επιλογές βιβλίου και υφιστάμενη γεωμετρία. |
| `config/editorial-config.tex` | Τυπογραφική βάση MINIMAL της v1.0.11. |
| `config/stable-*.tex` | Κοινές νέες παράμετροι της v1.0.12. |
| `config/color-map.json` | Μητρώο χρωμάτων, υφιστάμενων ρόλων και assets. |
| `styles/book-editorial-openings.tex` | Άνοιγμα και τίτλος πρώτης σελίδας περιεχομένου. |
| `styles/book-callouts.tex` | ThinkBox / AttentionBox / HistoryBox, κοινή κατασκευή. |
| `styles/book-stable-*.tex` | Κεντρικές αλλαγές της v1.0.12. |
| `styles/book-longtables.tex` | Πολυσέλιδοι πίνακες, επαναλαμβανόμενες κεφαλίδες. |
| `styles/book-figures.tex` | Αμετάβλητες συμβάσεις διαγραμμάτων. |

Οι θεματικοί τίτλοι παραμένουν Noto Serif Medium 11,7 pt σε λευκό χαρτί,
με λεπτή υπογράμμιση. Δεν επιλέγουμε την παλιά REFINED για νέο βιβλίο.
Το πρώτο πραγματικό περιεχόμενο κάθε custom κεφαλαίου λαμβάνει μία φορά
τίτλο Noto Serif Medium 17,5 pt και ένδειξη κεφαλαίου Inter Medium 9,5 pt.
Η αναμονή τίτλου λειτουργεί και όταν προηγείται clearpage φύλλου ή κριτηρίου.

Κυρίως σώμα Inter Regular 10,95 pt, section/subsection 13/11 pt,
τίτλος παραδείγματος 10,7 pt, «Λύση» 10,2 pt, τίτλοι των τριών διδακτικών
κουτιών 9,5 pt και σώμα τους 10 pt. STIX Two Math μέσω unicode-math ×1,05,
χωρίς δεύτερη αύξηση display. Ετικέτες διαγραμμάτων 9,5 pt, διαβαθμίσεις
8,5 pt. Κεφαλίδες/υποσέλιδα 8 pt. Περιθώρια: 20/17/19/20 mm
εσωτερικό/εξωτερικό/επάνω/κάτω.

Το ThinkBox έχει λευκό χαρτί και λεπτή αριστερή γραμμή, η «Προσοχή» φόντο
δεύτερου μελανιού 10% και η «Ιστορία» μαύρο 10%, αμφότερα χωρίς πλήρες
περίγραμμα. Τίτλοι, εικονίδια και αριστερές γραμμές έχουν δεύτερο μελάνι 100%.
Οι λεζάντες χρησιμοποιούν μόνο στο πρόθεμα/αριθμό το υπάρχον δεύτερο
μελάνι 55%· η περιγραφή είναι μαύρη. Οι γκρι πίνακες αξιοποιούν μαύρο 10%.

Οι ελεγχόμενες εντολές `make test`, `make preflight` και `make preflight-all`
και τα υφιστάμενα build targets διατηρούνται για συμβατότητα.
Τα tests, stress και δείγματα ελέγχου δεν φορτώνονται από το starter ως ύλη.
Νέα assets δηλώνονται στο μητρώο και χρησιμοποιούνται με `\BookUseAsset{key}`.
Το λογότυπο κεφαλίδας παραμένει το ίδιο διανυσματικό περίγραμμα.

Οι παλιότερες οδηγίες στο `archive/legacy-docs/` είναι ιστορικές.
Για τη v1.0.12 ακολουθούμε τα παρόντα έγγραφα και την τελική αναφορά QA.
Η stable μακέτα δεν συνεπάγεται πιστοποίηση PDF/X· οι
[προδιαγραφές τυπογραφείου](docs/PRESS_PENDING.md) παραμένουν εκκρεμείς.
Push, merge ή release στο απομακρυσμένο repository χρειάζονται χωριστή άδεια.
