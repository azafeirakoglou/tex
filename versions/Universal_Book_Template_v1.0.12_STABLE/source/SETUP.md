# Αναπαραγωγή v1.0.12 — MINIMAL

Οι πηγές είναι πλήρεις στο `source/`. Η ροή εγκατάστασης και build βρίσκεται
στο [../REPRODUCTION.md](../REPRODUCTION.md), από τη ρίζα του πακέτου.
Οι δύο χρωματικές εκδόσεις χρησιμοποιούν ακριβώς την ίδια ύλη και γεωμετρία.

Οι κλειδωμένες Inter, Noto Serif και STIX Two Math, οι άδειες και τα ελληνικά
πρότυπα συλλαβισμού περιλαμβάνονται στο `../runtime/`. Το τοπικό setup
επαληθεύει τις εξαρτήσεις και χρησιμοποιεί τα εγκατεστημένα Linux,
XeLaTeX/TeX Live, latexmk και fontconfig. Δεν χρειάζεται να αντιγραφεί
παλιό `.local/`, build directory ή compiled format.

Τα `.local/`, `build/`, formats, aux και caches δημιουργούνται εκ νέου
μέσα στον νέο φάκελο. Δεν αποτελούν πηγές ούτε αλλάζουν προηγούμενη stable.
Οι δημόσιες εντολές συγγραφής και το `scripts/build.py` διατηρούνται.

Το `config/editorial-design.tex` παραμένει στη MINIMAL. Η επιλογή A/B
της v1.0.12 αφορά μόνο κεφαλίδες παραδειγμάτων και τεκμηριώνεται στον
[οδηγό συγγραφής](docs/AUTHORING.md).

Οι παλαιότεροι μηχανισμοί release/export παραμένουν ως υπάρχουσες
λειτουργίες. Δεν χρησιμοποιούνται για απομακρυσμένη δημοσίευση στην παρούσα
εργασία. Push, merge και release χρειάζονται χωριστή έγκριση.
Η τοπική stable μακέτα δεν αποτελεί πιστοποίηση τυπογραφείου ή PDF/X.
