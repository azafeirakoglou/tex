# v0.18 — Ομαδοποίηση Φύλλων Εργασίας και Κριτηρίων ανά Κεφάλαιο

Η βασική διόρθωση του πίνακα περιεχομένων βρίσκεται στο αρχείο `styles/universalbook.sty`.

- Κεφάλαια: επίπεδο `chapter` (π.χ. «1 Κίνηση σε μία διάσταση»).
- Κατηγορίες «Φύλλα εργασίας», «Κριτήρια Αξιολόγησης»: επίπεδο `section`, χωρίς αρίθμηση 1.3, μόνο ο τίτλος σε δεύτερο χρώμα.
- Κάθε επιμέρους φύλλο ή κριτήριο: επίπεδο `subsection`, ο τίτλος μαύρος.
- Όλοι οι αριθμοί σελίδων στον πίνακα περιεχομένων: μαύροι.
- Δεν έχουν αλλάξει τα εσωτερικά σχέδια φύλλων/κριτηρίων.

**Σειρά αρχείων:** Στο `book-content.tex` το δοκιμαστικό κριτήριο της Κινηματικής μπήκε αμέσως μετά από το Φύλλο Εργασίας της Κινηματικής και *πριν* από το επόμενο κεφάλαιο Μαθηματικών. Έτσι το TOC δείχνει σωστά τη σχέση κεφαλαίου–συμπληρωματικού υλικού.

Τα νέα φύλλα και κριτήρια μπαίνουν στο `book-content.tex` κάτω από το ΚΕΦΑΛΑΙΟ στο οποίο ανήκουν. Δεν απαιτείται καμία ειδική εντολή από τον συγγραφέα για τον πίνακα περιεχομένων.

Για μεταγλώττιση: `make screen` και `make print2`. Χρησιμοποιούνται οι ίδιες πηγές στις δύο εκδόσεις. Το PRINT PDF παραμένει τεχνικό δοκίμιο και χρειάζεται την τελική έγκριση τυπογραφείου.
