# Σχήματα / διαγράμματα — κατάσταση αποφάσεων v0.31

**ΔΕΝ έχει ακόμη εγκριθεί συνολική προδιαγραφή σχεδίασης σχημάτων και γραφημάτων για το παρόν έργο.**

Το `styles/book-figures.tex` περιέχει **δοκιμαστικά**, όχι δεσμευτικά TikZ/PGFPlots styles. Ορισμένα ονόματα (`book/velocity`, `book/friction`, `book/accel`, `book/force`) εμφανίζονται σε παλαιά ενδεικτικά σχήματα. Δεν σημαίνει ότι έχουν συμφωνηθεί χρώματα για αυτά τα φυσικά μεγέθη.

**Δεν έχουν εγκριθεί:** χρωματική αντιστοίχιση ταχύτητας, επιτάχυνσης, δυνάμεων, βάρους ή τριβής· πάχος ή μοτίβα γραμμών· εικονογραφική γλώσσα· προεπιλεγμένη φορά αξόνων για συγκεκριμένα φυσικά προβλήματα· ιδιαίτερες συμβάσεις PGFPlots. Οποιοδήποτε από αυτά χρειάζεται ρητή απόφαση του υπευθύνου του έργου.

**Ήδη συμφωνημένος εκτυπωτικός περιορισμός:** ίδια φυσικά δεδομένα και γεωμετρία σχήματος σε SCREEN/PRINT, PRINT αποκλειστικά δύο μελάνια με εγκεκριμένες (όταν οριστικοποιηθούν) τονικότητες. Οι εικόνες και οι φωτογραφίες μπορεί να χρειάζονται ξεχωριστή προετοιμασία για την εκτύπωση.

Το προγενέστερο κείμενο με παραδείγματα φυλάσσεται μόνο για ιστορική αναφορά στο `docs/legacy_drafts/ΠΑΛΑΙΟ_ΠΡΟΣΧΕΔΙΟ_ΣΧΗΜΑΤΩΝ_v0.30.md`. **Δεν αποτελεί οδηγό ούτε εξουσιοδότηση AI συγγραφής.**

Η πλήρης τεκμηρίωση AI συγγραφέα, AI συντηρητή και ελληνικό εγχειρίδιο ανθρώπων συντάσσεται **μετά** την έγκριση Θάλειας και Έλσας.
