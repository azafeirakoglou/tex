# v0.19 — Ιεραρχία περιεχομένων και εξάσκηση

1. Όλες οι εγγραφές στον πίνακα περιεχομένων επιστρέφουν στο μαύρο. Δεν εμφανίζεται BookPrimary στους τίτλους ομάδων (Φύλλα εργασίας / Κριτήρια Αξιολόγησης).
2. Παραμένει η ένταξη των φύλλων και των κριτηρίων στο αντίστοιχο κεφάλαιο.
3. Στο δοκιμαστικό κεφάλαιο Φυσικής προστέθηκε `\section{Εφαρμογές και εξάσκηση}` πριν από τα Λυμένα παραδείγματα. Κάτω από αυτήν εξακολουθούν να εμφανίζονται οι ήδη εγκεκριμένες λωρίδες Λυμένα παραδείγματα / Ερωτήσεις θεωρίας / Άλυτες ασκήσεις.
4. Η απόσταση πριν από τις λωρίδες ρυθμίστηκε κεντρικά από 13pt σε 10pt. Οι συγγραφείς δεν χρειάζονται χειροκίνητα κενά.
5. Δεν τροποποιήθηκαν οι ασκήσεις, τα κριτήρια, τα φύλλα εργασίας ή οι χρωματικές παλέτες SCREEN/PRINT.

## Οδηγία συγγραφής

```text
\section{Εφαρμογές και εξάσκηση}
\BookSection{Λυμένα παραδείγματα}
% ...
\BookTheorySection{Ερωτήσεις θεωρίας}
% ...
\BookSection{Άλυτες ασκήσεις}
% ...
```

Οι αριθμοί των σελίδων ενημερώνονται με 2–3 μεταγλωττίσεις XeLaTeX.
