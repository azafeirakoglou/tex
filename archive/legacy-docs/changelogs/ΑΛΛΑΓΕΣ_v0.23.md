# v0.23 — Ενοποίηση πινάκων

- Νέα `BookStripedTable` / `BookPlainTable`, με κοινό μέγεθος, γραμματοσειρά, κεφαλίδα, padding και στοίχιση· μόνο η εναλλαγή χρώματος αλλάζει.
- Παραμετρικές ρυθμίσεις στο `book-config.tex`.
- Δοκιμαστικός πίνακας Φυσικής μεταφέρθηκε στο νέο striped. Ο πίνακας Μαθηματικών μεταφέρθηκε στο νέο plain.
- Παλιό `BookColorTable` διατηρήθηκε ως συμβατό alias.
- Δύο δοκιμαστικές σελίδες και ελληνικός οδηγός.
- Δεν αλλάζουν κεφαλίδες, υποσέλιδα, ασκήσεις, περιεχόμενα και Κριτήρια Αξιολόγησης.
