# v0.25 — Κουτιά με κεντραρισμένα εικονίδια

## Αλλαγές
- Ενσωμάτωση της εγκεκριμένης παραλλαγής **Β** των δοκιμών v0.24: λάμπα στο `ThinkBox`, τρίγωνο με θαυμαστικό στο `AttentionBox`, μεγέθυνση 1.11, στο κατακόρυφο μέσο της αριστερής ζώνης, με αριστερή κάθετη γραμμή.
- Αφαιρέθηκαν τα Unicode σύμβολα από τη γραμμή των τίτλων. Τα παλιά commands διατηρούνται για λόγους συμβατότητας με άλλο κώδικα.
- Προστέθηκε κοινό εσωτερικό στυλ `BookCallout` για γεωμετρία, αποστάσεις, breakability. Δεν αποτελεί περιβάλλον συγγραφέα.
- Χρώματα/σύμβολα βασίζονται στη σημασιολογική παλέτα SCREEN/PRINT, διανυσματικά, χωρίς εξωτερικές εικόνες.
- Προστέθηκαν `callouts-v025-screen.tex`, `callouts-v025-print2.tex`, `callouts-v025-content.tex` ως ανεξάρτητα δείγματα.
- **Δεν προστέθηκε** το `CommonMistakeBox`/«Συχνό λάθος», επειδή εκκρεμεί εκδοτική απόφαση.

## Χρήση από συγγραφέα (καμία αλλαγή)
```latex
\begin{ThinkBox}
Σκέφτομαι πρώτα τη θετική φορά...
\end{ThinkBox}
\begin{AttentionBox}
Οι μονάδες πρέπει να είναι συμβατές.
\end{AttentionBox}
```

## Τεχνικές παρατηρήσεις
- `BookCallout` ορίζει κοινή αριστερή ζώνη `17.5mm`, εσωτερικά κενά, `breakable`.
- `\BookCalloutIconScale=1.11` και `\BookCalloutIconOffset=8.7mm` ορίζονται κεντρικά στο `config/book-config.tex`.
- `overlay unbroken` και `overlay first` τοποθετούν εικονίδιο στο `frame.west` (κέντρο πρώτου τμήματος σε διακοπή σελίδας).
- Το εικονίδιο δεν επαναλαμβάνεται σε επόμενο τμήμα πολυσέλιδου κουτιού.
- Οι παλιές ρυθμίσεις unicode `\AlertSymbolText` και `\ThinkSymbolText` δεν επηρεάζουν πλέον το νέο εικονίδιο.
