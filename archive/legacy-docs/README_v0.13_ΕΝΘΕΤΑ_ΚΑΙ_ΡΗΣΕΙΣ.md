# v0.13 — Ιστορίες από τη Φυσική και ρήσεις

**Κατάσταση:** δοκιμαστική μακέτα προς οπτικό έλεγχο. Το διχρωμικό PDF εξακολουθεί να είναι τεχνικό δοκίμιο, όχι εγκεκριμένο εκτυπωτικό master.

## Αλλαγές

- Το υπάρχον `HistoryBox` παραμένει **breakable**, αλλά τώρα έχει διακριτικό γκρι φόντο, λεπτή γκρι αριστερή γραμμή και τίτλο «Ιστορίες από τη Φυσική». Δεν χρησιμοποιείται κίτρινο/ώχρα.
- Η ψηφιακή έκδοση χρησιμοποιεί χρώματα `F1F1F1` / `686868`· το εκτυπωτικό προφίλ επιτρέπει μόνο `ProofBlack20` / `ProofBlack55` στο ιστορικό ένθετο, χωρίς τρίτο μελάνι.
- Η νέα εντολή `\BookQuote` **δεν έχει πλαίσιο, σκίαση ή γραμμή**. Χρησιμοποιεί Noto Serif italic, ένα ελαφρά μεγαλύτερο μπλε/spot εισαγωγικό και διακριτική απόδοση δημιουργού/πηγής.
- Και τα δύο στοιχεία προστέθηκαν στο δείγμα θεωρίας και στο συνεργατικό δείγμα.

## Παράδειγμα

~~~text
\begin{HistoryBox}[Ο Γαλιλαίος]
Γράφουμε εδώ το ιστορικό κείμενο...
\end{HistoryBox}

\BookQuote{Το κείμενο της ρήσης.}{Όνομα δημιουργού}[Πηγή]
~~~

Η πηγή είναι προαιρετική: `\BookQuote{Ρήση}{Δημιουργός}`.

## Πού αλλάζει η εμφάνιση

- `config/book-config.tex`: `\LabelHistory`.
- `config/palette-screen.tex`: `mycolor5`, `mycolor6` (γκρι).
- `config/palette-print2-spot.tex`: `mycolor5`, `mycolor6` (μαύρο 20/55%).
- `styles/universalbook.sty`: οι μοναδικοί ορισμοί `HistoryBox`, `\BookQuote`.

Η ρήση που παρουσιάζεται είναι πρωτότυπο δείγμα, **όχι ιστορικό παράθεμα**. Σε πραγματικές ρήσεις πρέπει να ελέγχεται η απόδοση και η πηγή.

Για τις τέσσερις εξόδους: `make all` (ή μόνο `make screen print2`).
