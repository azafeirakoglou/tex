# Αυτόματες καταχωρίσεις Φύλλων Εργασίας και Κριτηρίων Αξιολόγησης (v0.17)

Η διόρθωση γίνεται **κεντρικά** στο `styles/universalbook.sty`. Δεν απαιτούνται αλλαγές στα αρχεία `chapters/*.tex`.

## Φύλλο εργασίας

```text
\WorksheetOpening{ΚΙΝΗΜΑΤΙΚΗ}{Θέση, μετατόπιση και ερμηνεία διαγραμμάτων}
```

Στα περιεχόμενα θα δημιουργηθούν οι γραμμές:

```text
Φύλλα εργασίας                                      [σελίδα]
    Φύλλο εργασίας 1 — Θέση, μετατόπιση και ερμηνεία διαγραμμάτων
```

## Κριτήριο Αξιολόγησης

```text
\begin{Assessment}[duration={90 λεπτά}]{Ευθύγραμμη κίνηση}
...
\end{Assessment}
```

Στα περιεχόμενα θα εμφανιστούν:

```text
Κριτήρια Αξιολόγησης                               [σελίδα]
    Κριτήριο Αξιολόγησης 1 — Ευθύγραμμη κίνηση
```

Αν υπάρχουν περισσότερα διαδοχικά φύλλα ή κριτήρια, ο γενικός τίτλος δεν επαναλαμβάνεται. Αν παρεμβληθεί κανονικό κεφάλαιο ή άλλη ομάδα υλικού, η επόμενη ομάδα ξεκινά νέα κύρια καταχώριση. Οι τίτλοι παραπέμπουν με κλικ στην αντίστοιχη αρχική σελίδα.

**Σημαντικό:** `xelatex` πρέπει να εκτελείται δύο φορές. Με `make screen` ή `make print2` αυτό γίνεται ήδη αυτόματα.

Η αλλαγή επηρεάζει μόνο τον πίνακα περιεχομένων και όχι την εμφάνιση των ασκήσεων και των διαγωνισμάτων.
