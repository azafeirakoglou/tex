# Universal Book Template v0.44 — φτερό και μελανοδοχείο

Το εικονίδιο βιβλίου στα «Ιστορίες από τη Φυσική» αντικαταστάθηκε με νέο
διανυσματικό φτερό καλλιγραφίας και μελανοδοχείο. Η αλλαγή εφαρμόζεται στην
κοινή δήλωση HistoryBox και χρησιμοποιείται παντού σε PRINT και SCREEN.

Το σχέδιο βρίσκεται στο styles/book-history-icon.tex και έχει περίπου
9,14 × 10,24 mm διαδρομές. Χρησιμοποιεί αποκλειστικά BookHistory (55% μαύρο),
με πάχη 0,90/0,68 pt. Δεν περιλαμβάνει raster εικόνες ή διαφάνειες.
Μέγεθος και πάχη ρυθμίζονται από τις BookHistoryIconScale/OutlineWidth/DetailWidth.

Πέρασαν 20 υπάρχοντες έλεγχοι χρωμάτων/κοινής κατασκευής και οι πραγματικοί
έλεγχοι μελανιών/αντιστοίχισης των 9 ζευγών PDF. Η σύγκριση με τη v0.43
επιβεβαιώνει ίδιο κεντράρισμα, πάχη, χρώμα, πλαίσιο και θέσεις του κυρίως
κειμένου. Τα κύρια PDF παραμένουν 20 σελίδες και τα 18 παραγόμενα PDF έχουν
82 σελίδες συνολικά, χωρίς overfull boxes.

Τα PDF παραμένουν δοκίμια μέχρι να δοθούν οι προδιαγραφές τυπογραφείου.
