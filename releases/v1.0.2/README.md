# Universal Book Template v1.0.2 — stable μακέτα

Κοινή χρωματική έμφαση για τα τρία διδακτικά κουτιά «Προσοχή»,
«Πώς σκέφτομαι» και «Ιστορίες από τη Φυσική».

| Στοιχείο και των τριών κουτιών | SCREEN | PRINT |
|---|---|---|
| Τίτλος, εικονίδιο, αριστερή και λεπτές γραμμές | Μπλε 100%, `#203B63` | Κόκκινο spot 100% |
| Κυρίως κείμενο | Μαύρο 100% | Μαύρο 100% |

Μία κεντρική τιμή, `BookCalloutAccent: Spot100` στο `config/color-map.json`,
χρωματίζει όλα τα παραπάνω στοιχεία. Τα ενεργά εικονίδια χρησιμοποιούν
αποκλειστικά τον ίδιο ρόλο για κάθε γραμμή και γέμισμα. Αλλαγή αυτού του
ενός ρόλου και εκτέλεση `make colors-regenerate` ενημερώνει και τα τρία κουτιά.

Τα φόντα διατηρούνται: 10% δεύτερου μελανιού σε «Προσοχή»/«Πώς σκέφτομαι»,
10% μαύρο στις «Ιστορίες». Οι γραμμές παραμένουν 2 pt αριστερά και 0,35 pt
στις άλλες πλευρές. Το περίγραμμα της εκφώνησης λυμένου παραδείγματος
παραμένει 0,35 pt στο 55% δεύτερου μελανιού.

Οι παλιοί χρωματικοί ρόλοι διατηρούνται για συμβατότητα και άλλες χρήσεις,
ώστε η ενοποίηση των κουτιών να μην αλλάζει πηγές αποφθεγμάτων ή εικαστικά
του εξωφύλλου. Το περιεχόμενο, οι γραμματοσειρές και η γεωμετρία διατηρούνται.

## Έλεγχοι

Η πλήρης διαδικασία έκδοσης εκτελεί 64 δοκιμές, τους διαχωρισμούς των
11 ζευγών PDF και τον έλεγχο του δοκιμίου 68 σελίδων. Επιπλέον ελέγχθηκαν
ξεχωριστά τα χρώματα των τίτλων, των διανυσματικών γραμμών/γεμισμάτων κάθε
εικονιδίου και των περιγραμμάτων στα πραγματικά PRINT και SCREEN PDF.

Η αναφορά `clean-install.json` καταγράφει επανεγκατάσταση από το ίδιο ZIP
σε νέο φάκελο/περιβάλλον Python, με νέα λήψη γραμματοσειρών, όλες τις
μεταγλωττίσεις/δοκιμές και σύγκριση των 22 PDF με το checkout αναφοράς.
Το ZIP διατηρείται ακριβώς όπως ελέγχθηκε και η αναφορά περιλαμβάνει το hash του.

Οι προηγούμενες εκδόσεις διατηρούνται χωρίς αντικατάσταση. Το πραγματικό
κόκκινο spot, η έγκριση των τόνων 100/55/10%, το ξάκρισμα και το ζητούμενο
PDF/X/ICC παραμένουν στις γνωστές εκκρεμότητες τυπογραφείου. Τα PRINT PDF
είναι δοκίμια μέχρι να εφαρμοστούν αυτές οι προδιαγραφές.
