# Universal Book Template v1.0.3 — stable μακέτα

Κεντρική εμφάνιση για όλες τις αριθμημένες λίστες και τις ενδείξεις λύσεων.

| Ετικέτες | SCREEN | PRINT |
|---|---|---|
| `1. 2. 3.`, `α) β) γ)`, `i) ii) iii)` και ενδείξεις λύσεων | Μπλε 100%, `#203B63` | Κόκκινο spot 100% |
| Κείμενο κάθε στοιχείου | Μαύρο 100% | Μαύρο 100% |

- Ο κοινός χρωματικός ρόλος είναι `BookListAccent: Spot100` στο
  `config/color-map.json`. Η `BookListLabelColor` δείχνει σε αυτόν.
- Η κοινή `BookListLabelFont` εφαρμόζει το χρώμα και την έντονη γραφή σε
  `enumerate`, εμφωλευμένες λίστες, `greeklist` και `BookGreekItems`.
- Οι δύο τοπικές επιλογές χρώματος αφαιρέθηκαν. Οι τέσσερις χειροκίνητες
  ενδείξεις α)/β) των λύσεων χρησιμοποιούν την ίδια `BookListLabel{...}`.
  Το χρώμα/βάρος περιορίζονται στην ένδειξη και δεν διαρρέουν στο κείμενο.
- Οι μορφές αρίθμησης, οι αποστάσεις και τα περιθώρια των λιστών διατηρούνται.
  Άλλες χρήσεις του μεσαίου τόνου, όπως οι επιλογές Σ/Λ, παραμένουν ανεξάρτητες.

Για κοινή αλλαγή χρώματος επεξεργαζόμαστε τον `BookListAccent` και εκτελούμε
`make colors-regenerate`. Για ένδειξη μέσα σε λύση γράφουμε, για παράδειγμα,
`\BookListLabel{α)}`. Η εντολή μορφοποιεί το κείμενο και δεν αυξάνει μετρητή.

## Έλεγχοι

Η πλήρης διαδικασία έκδοσης εκτελεί 64 δοκιμές, τους διαχωρισμούς των
11 ζευγών PDF και τον έλεγχο του δοκιμίου 68 σελίδων. Επιπλέον σαρώθηκαν οι
πραγματικές ετικέτες των λιστών και των λύσεων στα 22 PDF: οι τρεις μορφές
αρίθμησης εμφανίζονται στο 100% και το επόμενο κείμενο παραμένει μαύρο.

Η αναφορά `clean-install.json` καταγράφει την επανεγκατάσταση από το ίδιο
ZIP σε νέο φάκελο/περιβάλλον Python, με νέα λήψη γραμματοσειρών, όλες τις
μεταγλωττίσεις/δοκιμές και σύγκριση των 22 PDF με το checkout αναφοράς.
Το ZIP διατηρείται ακριβώς όπως ελέγχθηκε και η αναφορά περιλαμβάνει το hash του.

Οι προηγούμενες εκδόσεις διατηρούνται χωρίς αντικατάσταση. Το πραγματικό
κόκκινο spot, η έγκριση των τόνων 100/55/10%, το ξάκρισμα και το ζητούμενο
PDF/X/ICC παραμένουν στις γνωστές εκκρεμότητες τυπογραφείου. Τα PRINT PDF
είναι δοκίμια μέχρι να εφαρμοστούν αυτές οι προδιαγραφές.
