# Universal Book Template v0.35 — κοινά διδακτικά κουτιά

Ενιαίος μηχανισμός κατασκευής ThinkBox, AttentionBox, HistoryBox στο `styles/book-callouts.tex`: ίδιος τίτλος, γραμμή, γεωμετρία και θέση εικονιδίου.

| Κουτί | Τίτλος / γραμμή / εικονίδιο | Φόντο |
|---|---|---|
| Πώς σκέφτομαι | 55% δεύτερου μελανιού | 10% δεύτερου μελανιού |
| Προσοχή | 55% δεύτερου μελανιού (πριν 100%) | 10% δεύτερου μελανιού |
| Ιστορίες από τη Φυσική | 55% μαύρου | 10% μαύρου |

Τα φόντα βρίσκονται ήδη στον πιο αχνό διαθέσιμο τόνο10%. Το νέο εικονίδιο βιβλίου σχεδιάστηκε από την αρχή με πλατιές καμπύλες σελίδες, εξώφυλλο και καθαρή κεντρική πτύχωση.
