# Universal Book Template v1.0.4 — stable μακέτα

Ουδέτερο πλαίσιο εκφώνησης λυμένου παραδείγματος με χρωματική έμφαση
στα γράμματα τίτλου και στη λέξη «Λύση».

| Στοιχείο | SCREEN | PRINT |
|---|---|---|
| Φόντο εκφώνησης | Μαύρο 10%, `#E6E6E6` | Μαύρο 10% |
| Λεπτό εξωτερικό περίγραμμα | Μαύρο 55%, `#737373` | Μαύρο 55% |
| Περιοχή τίτλου | Χωρίς ξεχωριστό γέμισμα, στο κοινό γκρι φόντο | Χωρίς ξεχωριστό γέμισμα, στο κοινό γκρι φόντο |
| Γράμματα τίτλου και «Λύση» | Μπλε 100%, `#203B63` | Κόκκινο spot 100% |
| Κείμενο εκφώνησης | Μαύρο 100%, `#000000` | Μαύρο 100% |

Το περίγραμμα διατηρεί το κοινό λεπτό πάχος 0,35 pt. Οι χρωματικοί ρόλοι
ορίζονται στο `config/color-map.json`: `BookProblemBackground = Black10`,
`BookProblemBorder = Black55`, `BookExampleAccent = Spot100`.

Η ξεχωριστή βαφή της περιοχής τίτλου απενεργοποιείται με `title filled=false`.
Το κοινό γκρι φόντο συνεχίζεται πίσω από τον τίτλο και την εκφώνηση, χωρίς
διαφάνεια ή νέα τονικότητα. Η γεωμετρία, οι αποστάσεις και οι θέσεις κειμένου
παραμένουν ίδιες με τη v1.0.3. Ο ιστορικός διακόπτης `BookExampleDarkHeader`
επιλέγει τη διάταξη τίτλου και διατηρείται για συμβατότητα· και οι δύο μορφές
έχουν πλέον ουδέτερο φόντο/περίγραμμα.

## Έλεγχοι

Η πλήρης διαδικασία έκδοσης εκτελεί 64 δοκιμές, τους διαχωρισμούς των
11 ζευγών PDF και τον έλεγχο του δοκιμίου 68 σελίδων. Επιπλέον ελέγχθηκαν
οι πραγματικές βαφές, τα περιγράμματα, τα χρώματα γραμμάτων και οι θέσεις
των εκφωνήσεων: το γκρι 10% συνεχίζεται πίσω από τον τίτλο χωρίς πρόσθετο
έγχρωμο γέμισμα και το περίγραμμα είναι μαύρο 55%. Η εναλλακτική διάταξη
μεταγλωττίστηκε και ελέγχθηκε χωριστά σε PRINT και SCREEN.

Η αναφορά `clean-install.json` καταγράφει επανεγκατάσταση από το ίδιο ZIP
σε νέο φάκελο/περιβάλλον Python, με νέα λήψη γραμματοσειρών, όλες τις
μεταγλωττίσεις/δοκιμές και σύγκριση των 22 PDF με το checkout αναφοράς.
Το ZIP διατηρείται ακριβώς όπως ελέγχθηκε και η αναφορά περιλαμβάνει το hash του.

Οι προηγούμενες εκδόσεις διατηρούνται χωρίς αντικατάσταση. Το πραγματικό
κόκκινο spot, η έγκριση των τόνων 100/55/10%, το ξάκρισμα και το ζητούμενο
PDF/X/ICC παραμένουν στις γνωστές εκκρεμότητες τυπογραφείου. Τα PRINT PDF
είναι δοκίμια μέχρι να εφαρμοστούν αυτές οι προδιαγραφές.
