# Αλλαγές v0.22 — Προεπιλογές κεφαλίδων και υποσέλιδων

- `BookAssessmentHeaderLabel=Κριτήριο αξιολόγησης`: πεζοκεφαλαία στις κεφαλίδες, όπως και το `Ενότητα`. Οι τίτλοι κεφαλαίων εμφανίζονται με την αρχική γραφή τους (`\nouppercase` ήδη υπήρχε).
- `BookFooterMode=number`: στο υποσέλιδο εμφανίζεται μόνο `\thepage`.
- `BookFooterPosition=outer`: αριστερή/εξωτερική θέση στις ζυγές, δεξιά/εξωτερική θέση στις μονές.
- Η μπλε λωρίδα «ΚΡΙΤΗΡΙΟ ΑΞΙΟΛΟΓΗΣΗΣ» δεν αλλάζει.
- Οι προηγούμενοι τύποι `full` / `center` παραμένουν ως επιλογές.
- Οι αλλαγές είναι μόνο στις κεντρικές ρυθμίσεις. Δεν χρειάζονται διορθώσεις σε αρχεία κεφαλαίων, ασκήσεων ή κριτηρίων.
- Οι δίχρωμες εκτυπωτικές προδιαγραφές εξακολουθούν να απαιτούν έγκριση από τυπογραφείο.
